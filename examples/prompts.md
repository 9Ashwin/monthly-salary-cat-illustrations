# 使用与生成提示词

以下请求可交给支持本 skill 的 AI 助手。将占位符替换为你的正文，编辑请求需同时提供图片。

## 只做配图规划

```text
使用 $monthly-salary-cat-illustrations，先不要生图。
阅读下面的文章，只挑值得用图片解释的位置。
每张建议写清：放在哪段后、要表达什么、月薪喵在做什么、需要哪些物件、中文标注。
配图数量以内容为准，不要平均分配。

<粘贴文章>
```

## 为文章生成配图

```text
使用 $monthly-salary-cat-illustrations，为下面的文章生成 3 张独立配图。
白底、横版、深棕线条、白棕月薪喵，保留原型的脸型、蓝色小眼和短身体。
每张讲清一个核心结构，保留必要步骤、分支与反馈，月薪喵实际操作关键环节。请直接生成并保存图片。

<粘贴文章>
```

## 长文配图策略

```text
使用 $monthly-salary-cat-illustrations，先分析这篇长文哪里需要配图。
优先选观点转折、取舍、行动和状态变化；适合文字表达的部分保持文字。
只给配图建议，不生成图片。

<粘贴文章>
```

## 一个观点，一张图

```text
使用 $monthly-salary-cat-illustrations，为这个观点生成一张正文配图：
真正的进展，是先做出能验证的小部分。
画清楚做出小样、检查结果和决定下一步之间的关系，让月薪喵实际参与判断。
```

## 工作流主题

```text
使用 $monthly-salary-cat-illustrations，为“先澄清输入，再开始动手”生成一张图。

月薪喵保留原始形象，画面简洁，不画密集流程图。
```

## 改图：删掉标题

```text
使用 $monthly-salary-cat-illustrations，编辑提供的图片。
删去顶部标题，保留角色、标注、物件和构图，不增加新内容。
```

## 改图：校正角色

```text

```

## 一组不同主题的样片

```text

横向布局：散卡和小篮位于左约15%，素材柜约32%，写作台与文章约52%，短承接桥约73%，门洞约89%；修复说明在相应接头上方。主体居中横向展开，上下仍留呼吸空间。
```

### 02 · 最小闭环

[查看图片](images/02-minimum-loop.png)

实际交给执行者的请求：

```text
使用 $monthly-salary-cat-illustrations，为下面这段中文正文生成一张正文配图，保存 PNG：

一个最小内容闭环，要让外部信息、内部经验和用户反馈进入同一套判断过程。判断之后选择合适的内容形式，再把发布的内容连接到读者能继续行动的入口。入口产生的新问题和反馈要回到信息端，影响下一轮选题，而不是发布后就结束。
```

<summary>执行 skill 后形成的实际图像提示词</summary>

第 1 次图像调用：

```text
生成一张独立的 16:9 横版中文正文配图，PNG。Use case: infographic-diagram。用途是解释文章中的最小内容闭环。

参考图用途：第1张（原始宠物精灵图 monthly-salary-cat-original.webp）只锁定月薪喵的形象；第2张上游结构参考 02-minimum-loop.png 只校准功能环节、流向密度与横向布局。不要复制黑猫、原图中文、巨大机器、三层托盘或门的装置构图。本次采用开放式木桌、滑槽、选模转盘与回程夹绳的全新构图。

角色严格沿用第1张原始月薪喵参考中正面站姿：小三角耳，两耳间短而较平或微凹的顶部，清晰的锯齿状脸颊毛束，站姿头部与身体可见高度接近，身体短而略方，短爪、短毛束棕色尾巴。奶茶棕耳与头部两侧，奶白从额头中央窄三角向下展开到脸与躯干，深棕描边。眼睛是两条小而简练的短竖蓝线，无眼白，无巨大水滴；嘴是一条极小深棕横线，绝对没有W嘴。保持原型，不改成巨头圆脸、光滑圆身、大眼或光滑长卷尾。可以戴小蓝领带。图中仅两只形象一致的月薪喵，都有明确操作。

核心观点：三种材料经过共同判断与形式选择，发布后连接读者行动，再把新问题和反馈送回信息端，影响下一轮。
功能环节：
1. 信息端：左侧三束各不相同的材料，外部信息用新闻剪页、内部经验用打开的项目笔记、用户反馈用问号纸条；分别位于左侧上中下三个短斜滑槽，三槽共同汇入一个浅木质汇合盘，绝不能三个来源各走独立后续流程。
2. 汇合判断：汇合盘接一个小木制选题判断桌，第一只月薪喵短爪正在拨开桌上闸杆，将混合材料中的一页送往右侧；表示同一判断过程。猫在这步真实参与。
3. 选择形式：判断桌右边是一只低矮三格旋转模具盘，分别以无字的短纸卡、小册、带播放三角的小卡表示可选内容形式；旋钮正指向其中一格，只有被选的一张沿右侧滑槽送出，避免画成同时三路大量生产。此处准确写“选择形式”。
4. 发布内容：右侧滑槽把选好的完整内容夹在两根小木柱之间的短晾绳上，展示一张带深棕线条的已发布内容页。
5. 行动入口：内容页右侧以橙色箭头连接一处低矮、明确可到达的开放阅读与留言台，台上有翻开的说明小册和可投纸条的插口。第二只月薪喵站在此处，读完后正在将一张新问号纸条夹到下方回程夹绳，体现读者行动产生反馈。不要画成孤立信箱。

主线与箭头：外部信息→共同汇合盘，内部经验→共同汇合盘，用户反馈→共同汇合盘；汇合盘→汇合判断桌；判断桌→选择形式转盘；转盘被选出口→发布内容晾绳；发布内容→行动入口。全部主流向用短而清晰的橙色实线箭头，箭头的起点终点紧贴对应装置出入口，不穿过猫或标签。
反馈：从右端行动入口上第二只猫刚夹上的问号纸条出发，蓝色虚线方向向下、向左沿画面下部的水平回程夹绳走，最后向上抵达左侧“用户反馈”滑槽的入口。终点必须在这条输入滑槽内可见；蓝色箭头与问号纸条均指示向左再向上。回流只落到信息输入端，再通过已经画出的主线进入共同判断，从而改变下一轮，不在发布处中止、不悬空、不指向输出。

具象装置：一套开放木质工坊，三段短滑槽、浅汇合盘、小闸门桌、旋转选模盘、内容夹绳、行动留言台、回程夹绳。小而简洁，纸条贯穿装置，使输入和输出确实相连。
横向布局：三类信息在画面左侧约5%–20%；汇合判断在25%–42%；选择形式在47%–59%；发布内容在64%–75%；行动入口在81%–95%。主结构居中横向展开，动作区约在高度30%–67%，蓝色反馈回路位于70%–83%，标签在对应物件附近。两只猫各占画面宽约10%，不要巨大。整个主体利用大部分横向空间，约25%–35%留白，不把主体压在底部，也不固定空出上半幅。视觉整体像一幅连贯的轻松手绘正文插画。

图中实际出现的中文仅以下8处，使用清楚自然的深棕中文手写字，每处对应一个环节，不加其他文字：

“内部经验”
“用户反馈”
“汇合判断”
“选择形式”
“发布内容”
“行动入口”
“新问题与反馈”（这一处在蓝色反馈回路下方，用蓝色字）

纯白背景，简洁深棕手绘轮廓与干净平涂，奶白、奶茶棕为主，橙色仅代表前进，蓝色仅代表回流及猫的眼睛/领带。一图解释一个完整闭环，步骤与回路必须可追踪，关系优先但仍轻松可爱。不加大标题、口号、卡片边框、复杂背景、3D、写实毛发、腮红、爱心、高光大眼、无用装饰。不要用整齐矩形框堆成PPT流程图；不要省略“选择形式”或“行动入口”；不要让猫只是站在装置旁边。
```

### 03 · 先判断用途

[查看图片](images/03-sort-by-purpose.png)

实际交给执行者的请求：

```text
使用 $monthly-salary-cat-illustrations，为下面这段中文正文生成一张正文配图，保存 PNG：

同一批外部信号、自己的经验和用户问题，不应该一股脑直接写成文章。先判断这份材料要完成什么任务：让陌生人看见你、帮助读者建立信任，还是让已经认可的人采取下一步行动。材料经过用途判断，再分别进入相应的内容生产位置。
```

<details>
<summary>执行 skill 后形成的实际图像提示词</summary>

第 1 次图像调用：

```text
生成一张独立的 16:9 横版中文正文配图，PNG。Use case: infographic-diagram。适合穿插在中文正文中，无大标题。

参考图用途：图1是公开原始月薪喵精灵图，只锁定月薪喵的形象，尤其参考其中正面站姿和短爪伸出操作的姿态；图2上游“按目的分流”图只校准功能环节、流向密度与横向布局，不复制黑猫、原图中文、抽屉柜或把角色当加工机器的具体装置构图。

角色严格沿用图1的原始月薪喵：小三角耳，两耳间短而较平或微凹的顶部，锯齿状脸颊毛束，站姿头身高度接近，身体短而略方，短爪、短毛束尾巴。奶茶棕耳与头部两侧，奶白从额头中央窄三角向下展开到脸与躯干，深棕描边。小而简练的蓝色短竖眼睛，小深棕横嘴；困倦但认真，可使用原型正面站姿中的小蓝领带。保持原型，不改成巨头圆脸、大眼、W嘴或光滑长卷尾。

核心观点：同一批来源各异的材料先汇合，经过用途判断，再分流到三种内容生产位置。不能表现三种来源分别与三种用途一一配对，也不能让输入绕过判断台。
功能环节：
1. 左侧三类来源：外部信号、自己的经验、用户问题分别装入三个浅木篮，篮中是简笔纸条；三条短轨道明确汇合为同一条入口轨道。
2. 中央共同用途判断台：圆形木质道岔转盘接收所有混合材料，猫查看一张材料并拨动三向分流杆，决定材料承担什么任务。
3. 右上支路生产位置：材料抵达一个低矮斜面写作工作台，用于让陌生人看见你的内容；台上是带简易眼睛符号的展开纸张。
```
