# 示例验证

本目录记录 14 个正文配图任务的实际执行结果，用于检查 skill 能否把文章中的步骤、分支、对比和反馈画清楚。

- [evals.json](evals.json)：交给执行者的正文任务，保留原文。
- [results.json](results.json)：生成次数、图片尺寸与哈希、关系草案和视觉检查记录。
- [实际提示词](../examples/prompts.md)：各次图像调用的完整提示词，包括局部修正。
- [图片索引](../examples/README.md)：14 张最终 PNG。

## 执行方法

独立 AI 执行者收到 skill 路径、正文任务和输出位置，自行阅读技能、取得角色参考、分析关系并编写图像提示词。执行者调用图像工具后查看结果，有明确偏差时进行针对性修正。未向执行者提供预定构图或图像提示词。

程序检查 PNG 是否可解码、画幅是否接近 16:9、任务原文是否一致、提示词数量是否与调用次数一致，以及仓库展示图与安装包示例是否逐字节相同。视觉检查关注角色形状、中文、步骤顺序、分支和反馈落点。

## 记录范围

这些记录说明本轮具体任务的结果，不构成统计基准或未来生成质量的保证。视觉检查由 AI 查看图片完成，未运行自动 OCR、逐像素角色比对或精确留白测量。

这 14 张图片由先前使用上游结构参考图的版本生成。现版改用月薪喵示例校准结构，上游图片不再随包分发；移除这项依赖后未重新生图，因此本轮结果不能证明现版具有相同表现。执行后还整理了措辞与导航、收窄了触发范围，并明确纯角色状态图不要求流程装置。

实际提示词与执行者哈希保留历史原文。`results.json` 分别记录执行者提供的文件哈希和整理后的文本哈希，后者不代表各任务首次读取的版本。第 02、03 个任务的文件哈希在执行后记录，已单独注明。

当前安装包已内置原始角色 WebP；这次仅调整素材分发与读取位置，未重新生成示例。来源与许可范围见 [NOTICE.md](../NOTICE.md)。

安装验证覆盖明确指定 Codex 的非交互 CLI 安装，以及独立 Agent 按安装说明向隔离配置目录执行的 WorkBuddy 复制流程；两者均包含完整的 24 个技能文件，内容与来源一致，ZIP 包也已核验。复制流程没有在真实 WorkBuddy 中执行，不能据此声称其已识别或加载技能。

技能说明支持调用不同 Agent 已启用的参考图生成工具，但现有示例不构成跨平台验证。本项目尚未执行 WorkBuddy 生图测试，也不保证不同模型的生成效果相同。
