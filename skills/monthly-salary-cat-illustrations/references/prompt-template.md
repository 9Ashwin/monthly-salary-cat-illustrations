# 单图提示词

按[构图与隐喻](composition-patterns.md)完成草案，再填模板。将按[角色文档](monthly-salary-cat-ip.md)查看的原始单帧作为图像工具的实际输入，结构由本次关系草案描述。默认只附加 `assets/character-reference/front.png`，确需其他姿态时最多再选一帧；不要附加完整动作表。图片输入参数与文字提示分开处理，不能只写一个本地路径代替附图。无需现场分帧脚本或中间角色生成。

```text
生成一张独立的 16:9 横版中文正文配图，PNG。

参考图用途：{原始宠物图}用于锁定月薪喵的形象。按下面的关系与布局绘制新场景，不画精灵表。

角色严格沿用提供的原始月薪喵参考：小三角耳，两耳间短而较平或微凹的顶部，锯齿状脸颊毛束，站姿头身高度接近，身体短而略方，短爪、短毛束尾巴。奶茶棕耳与头部两侧，奶白从额头中央窄三角向下展开到脸与躯干，深棕描边。小而简练的蓝色眼睛或短竖泪条，小深棕横嘴；表情遵循相近原帧。领带只在本次姿态需要且符合参考时使用。保持原型，不改成巨头圆脸、大眼、W嘴或光滑长卷尾。

核心观点：{用一句话写清楚}
功能环节或对比状态：{逐项列出，通常3–5环节或2–4状态；说明进入什么、怎样变化、输出什么}
主线与箭头：{逐条列出起点→终点；主流向使用橙色实线箭头}
分支与反馈：{分支的不同去向；反馈从哪里回到哪里、改变什么，使用蓝色虚线箭头；确实没有则删掉此项}
具象装置：{用管道、闸门、晾绳、轨道等一套低科技物件承载上面的关系，写清进出口}
猫的操作：{每只猫在何处做什么、如何改变内容流动；可以有多只形象相同的猫承担不同角色}
横向布局：{输入/判断或处理/输出的位置，回路或对比区的位置；主体使用画布中心与大部分横向空间}
图中实际出现的中文：{逐项列出，通常5–8处必要短标注，每处尽量2–8字}

一图解释一个核心结构，结构中的步骤、分支与回路要完整可追踪，不能缩成一只猫加一句话。猫是正在操作装置的角色，不是旁站的吉祥物。纯白背景、深棕简洁描边、奶白与奶茶棕角色、少量语义色。约25%–35%留白，主结构放在画布中心，不挤在底部，不固定空出上半幅。中文只使用列出的标签，不添加海报标题或口号。避免整齐矩形框组成的PPT流程图、复杂背景、3D质感与无信息作用的装饰；功能关系不能因“极简”而消失。
```

提交前删除不适用的项，按用户要求调整比例、背景和文字。纯角色状态图只需状态、触发因素、动作与必要物件，删除装置、流向相关要求，不补造流程。不为填模板增加环节，也不删去题目要求的步骤、分支或反馈。新增仓库示例也使用此模板。

## 修改现有图

引用用户指定的图片，直接说明需要改变的部位与结果，例如：

```text
编辑提供的插图：将纸条上的“反馈”改为“回看”。保留其余文字、角色动作、配色、构图和画面比例；不要添加新元素。
```

角色偏离时，重新引用原始参考，指出需要修正的特征。关系不清时，明确要修复的连接、分支或回路。文字有误时优先局部编辑。无需反复传入全部示例，也不要单独以错误生成图作为下一轮角色依据。
